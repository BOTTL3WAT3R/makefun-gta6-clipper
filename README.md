A vertical YouTube Short cut by an AI agent from Grand Theft Auto VI Trailer 1 (Rockstar Games): an animal-control officer drags an alligator out of a backyard pool — the trailer's own caption calls it an "uninvited guest" — followed by two more only-in-Leonida beats (a dancer standing on a moving convertible at night, a man climbing out over his truck door) and a slow-motion replay of the gator. The clip closes with an on-screen pitch for make.fun. The rendered video is `final-clip.mp4` in this repository; `render.sh` holds the exact ffmpeg commands that found, cut and rendered it, and `UPLOAD.md` holds the title and description it is published with. `VIDEO.json` names the YouTube address of the published Short (a placeholder until the upload lands).

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
